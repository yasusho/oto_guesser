# Oto Guesser

お題として再生される音（TARGET）と、スライダーや波形ボタンで調整する音（YOURS）を聴き比べながら、同じ音を作り出す音当てゲームです。

## 特徴

- **マルチ単音・和音対応**: 1音（単音）のシンプルな音当てに加え、2音（和音）の聴き分けに切り替えて遊ぶことができます。
- **2つのゲームモード**:
  - **フリープレイ**: 気軽に音を合わせる練習ができるモードです。
  - **5問チャレンジ**: 5回のラウンドでどれだけ正確に音を合わせられるかスコアを競い合うモードです。最後に結果をクリップボードにコピーしてシェアできます。
- **Web Audio API による高品位サウンド**: 不快なクリック音やノイズを防ぐエンベロープ（Attack / Release）処理を適用し、快適な可聴域（100Hz〜1600Hz）で再生されます。

---

## 各モードのステップ仕様と難易度

音響の仕様を守りつつ、各モードの周波数調整範囲と波形の組み合わせ数を調整しました。

| モード (発音数) | 周波数レンジ (最小刻み) | 音色 (波形) | 総組み合わせ数 |
| :------------ | :--------------------------------- | :------------------ | :----------------: |
| **1音 (単音)** | 100 Hz 〜 1600 Hz (`1 Hz`) | サイン波 / 三角波 / ノコギリ波 / 矩形波 (`4種`) | **約 6,000通り** |
| **2音 (和音)** | 100 Hz 〜 1600 Hz (`1 Hz` × 2音) | サイン波 / 三角波 / ノコギリ波 / 矩形波 (`4種` × 2音) | **約 3,600万通り** |

- **難易度の統一と聴覚心理学評価**: 周波数誤差をヘルツ（Hz）ではなく人間の耳の認知に合わせた対数セント差（Cents Difference, 1オクターブ=1200セント）で計算し、単音でも和音でも公平に高精度なスコアが得られるよう設計しました。
